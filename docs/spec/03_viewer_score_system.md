# 視聴者・登録者システム（スコア設計）

> 注意：ここでの「配信」「チャンネル登録者数」は、いずれも**ゲーム内の演出・
> スコアシステム**であり、現実のマーケティング施策や実際の動画配信を指すもの
> ではない。プレイヤーキャラクターがゲーム内で配信活動を行っている、という
> 設定のもとでのスコアの見せ方を定義する。

## コンセプト

- プレイヤーキャラクターは、ファンタジーな塔を登っていく様子を配信している
- プレイの結果に応じて「チャンネル登録者数」が増減し、これがスコア兼勝敗条件になる
- 決め台詞：「みんなが見てない世界を見せてやるぜ」
- 登録者数1億人達成時、塔の中で手に入れたもの（金銀財宝など）を配ると宣言している
  （金銀財宝を手に入れるシーン自体はゲーム内の演出であり、実際のアイテム付与システムではない）

## チャンネル登録者数（決定）

- スタート：0人
- ゴール（勝利条件）：1億人
- ゲームオーバー条件：なし
- 登録者数は減少することがあり、その場合はゴールから遠ざかる（詰みにはならない）

### 増える条件（数値バランス決定）

塔には階数の上限がなく、プレイヤーが登り続ける限り増加要因も尽きない
（＝減少条件で多少ロスしても、登り続けることで必ず1億人に到達できる設計）。

| 要因 | 増加の傾向 | 数値 |
| --- | --- | --- |
| 塔を進めているだけ（通常進行・新しい階に到達するたび） | 少しずつ増加、上限なし | +1,500,000 / 階 |
| 一定階層（10階区切り）の到達 | 一気に増加、上限なし | +10,000,000 / 10階ごと |
| 金銀財宝の入手 | 一気に増加、上限なし | +3,000,000 / 8階ごとに1個 |

### 減る条件（数値バランス決定）

| 要因 | 備考 | 数値 |
| --- | --- | --- |
| 立ち止まり・放置 | 2.5秒操作なしで発生、継続する限りドレイン | -300,000 / 秒 |
| 落下 | 最高到達点から大きく（フロア2.5枚分以上）下に落ちた場合に発生。直前のチェックポイントへ引き戻される | -2,000,000（1回） |
| 被弾（硬直発生） | 敵に横・下から触れた場合。0.5秒怯み＋ノックバック、1.2秒の無敵時間付き | -2,000,000（1回） |
| 塔を降り続ける | 最高到達点からフロア0.9枚分以上下にいる状態が1.5秒以上継続した場合、継続する限りドレイン | -200,000 / 秒 |

## 画面表示・UI（決定）

実際の動画配信サイトのプレイヤー画面を模したレイアウトとする（`docs/spec/image.png` の
画面イメージに準拠）。ゲーム本編は画面左側の「動画エリア」に表示され、その周囲を配信サイト風の
UIが取り囲む。

- 動画エリア上部：「● LIVE」バッジ（明滅）、配信タイトル
- 動画エリア下部：決め台詞「みんなが見てない世界を見せてやるぜ」を開始時に表示しフェードアウト
- 動画エリア中央上寄り：登録者数の増減が5万人以上のときに要因
  （例：「+1,500,000 登頂中」「-2,000,000 被弾」）をポップアップ表示する（緑＝増加、赤＝減少）
- 下部バー：配信タイトル・登録者数（3桁区切り、増減の都度更新）・目標（1億人）に対する進捗バー・
  現在の到達階数（「現在 N 階」）・チャンネル情報（アイコン・チャンネル名・視聴中人数・登録ボタン・
  高評価/共有）
- 右側パネル：ライブチャット欄。常時、既存視聴者による雑談コメントが一定間隔で流れる
- 登録者数が増えるたび（通常進行・階層到達ボーナス・財宝入手）、その都度ランダムに生成された
  「新しい視聴者」がチャットに登録コメント（例：「登録しました!!」）を投稿する演出を行う。
  被弾・落下時は既存視聴者による反応コメントが流れる
- 1億人達成時は暗転＋達成メッセージ（「塔の中で手に入れたものは、ちゃんとみんなに配るぜ！」）と
  到達階数を表示し、「もう一度プレイ」ボタンでリスタートできる
