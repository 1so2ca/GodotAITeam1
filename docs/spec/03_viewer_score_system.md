# 視聴者・登録者システム（スコア設計）

プレイヤーキャラクターがゲーム内で配信活動を行っている、という設定のもとでのスコアの見せ方を定義する。

## コンセプト

- プレイヤーはゲーム内でキャラクターを操作し、その様子が「配信」されている体で進行する
- プレイのうまさ・成果に応じて、ゲーム内の「視聴者数」が増減する
- 一定の視聴者数・条件を達成すると「チャンネル登録者数」が増える（＝より安定した長期的スコア）
- 「Jump up!」というテーマ通り、視聴者数・登録者数が急上昇する瞬間を作ることが目的
