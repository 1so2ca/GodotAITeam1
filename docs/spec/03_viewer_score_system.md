# 視聴者・登録者システム（スコア設計）

> 注意：ここでの「配信」「チャンネル登録者数」は、いずれも**ゲーム内の演出・
> スコアシステム**であり、現実のマーケティング施策や実際の動画配信を指すもの
> ではない。プレイヤーキャラクターがゲーム内で配信活動を行っている、という
> 設定のもとでのスコアの見せ方を定義する。

## コンセプト

- プレイヤーキャラクターは、ファンタジーな塔を登っていく様子を配信している
- プレイの結果に応じて「チャンネル登録者数」が増減し、これがスコア兼勝敗条件になる
- 決め台詞：「みんなが見てない世界を見せてやるぜ」
- 登録者数1億人達成時、塔の中で手に入れたもの（金銀財宝など）を配ると宣言している
  （金銀財宝を手に入れるシーン自体はゲーム内の演出であり、実際のアイテム付与システムではない）

## チャンネル登録者数（決定）

- スタート：0人
- ゴール（勝利条件）：1億人
- ゲームオーバー条件：なし
- 登録者数は減少することがあり、その場合はゴールから遠ざかる（詰みにはならない）

### 増える条件（数値バランス決定）

塔には階数の上限がなく、プレイヤーが登り続ける限り増加要因も尽きない
（＝減少条件で多少ロスしても、登り続けることで必ず1億人に到達できる設計）。

| 要因 | 増加の傾向 | 数値 |
| --- | --- | --- |
| 塔を進めているだけ（通常進行・新しい階に到達するたび） | 少しずつ増加、上限なし | +1,500,000 / 階 |
| 一定階層（10階区切り）の到達 | 一気に増加、上限なし | +10,000,000 / 10階ごと |
| 金銀財宝の入手 | 一気に増加、上限なし | +3,000,000 / 8階ごとに1個 |

### 減る条件（数値バランス決定）

| 要因 | 備考 | 数値 |
| --- | --- | --- |
| 立ち止まり・放置 | 2.5秒操作なしで発生、継続する限りドレイン | -300,000 / 秒 |
| 被弾（硬直発生） | 敵に横・下から触れた場合。0.5秒怯み＋ノックバック、1.2秒の無敵時間付き | -2,000,000（1回） |
| 落下・塔を降り続ける | 最高到達点からフロア0.9枚分以上下にいる状態が1.5秒以上継続した場合に発生。「落下」に専用のテレポート等の特殊判定は設けず、物理挙動のまま一番下（安全床）まで自然に落下する。**継続ドレインではなく、まとめて一度だけ減点した時点で基準点（最高到達点）をその場にリセットし、自動減少を止める**（さらに離れればまた1.5秒後に再度減点される）。減点額は固定値ではなく、その時点の登録者数に対する割合（下に落ちたフロア数×5%、最低8%〜最大70%）。長時間・長距離の大転落では判定が繰り返し発生するため、高所からの大転落は登録者数が1万人前後まで落ち込むほどの大打撃になりうる | 登録者数 ×（下に落ちたフロア数×5%、8〜70%の範囲） |

## アイテム（決定）

塔を登るほどジャンプ力とフロア間隔の関係が単調になり間延びしてしまうため、
だれ防止・スピード感アップを狙って一定確率でフロアにアイテムを配置する
（チェックポイント階・財宝階・敵配置階を除く各階で15%の確率）。塔生成の乱数シードは
固定のため、確率任せだと同じ場所で連続して外れ続けることがある。抽選対象の階が
10回連続で外れたら強制的に出現させる「ピティ（保証枠）」を設け、必ず早い段階で
1つは入手できるようにしている。

| 種類 | 効果 | 持続時間 |
| --- | --- | --- |
| 無敵 | ダメージを受けない | 10秒 |
| ジャンプ力3倍 | ジャンプの初速が3倍になる | 10秒 |
| ロケット | 重力を切って直上に一定速度で上昇し続ける。左右移動は可能、ジャンプは不可。無敵状態も兼ねる。上昇中は足場を貫通する（壁・敵とは衝突する） | 3秒 |

取得すると画面にどの効果を得たかポップアップ表示する。

無敵状態（無敵アイテム・ロケット効果中）に敵へ触れた場合は、方向を問わず敵を撃破する
（通常時は真上からの踏みつけのみ撃破、それ以外は被弾になる）。

## 画面表示・UI（決定）

実際の動画配信サイトのプレイヤー画面を模したレイアウトとする（`docs/spec/image.png` の
画面イメージに準拠）。ゲーム本編は画面左側の「動画エリア」に表示され、その周囲を配信サイト風の
UIが取り囲む。

- 動画エリア上部：「● LIVE」バッジ（明滅）、配信タイトル「無限の塔登り配信中！～登録者数1億人へのカウントダウン開始！～」
- 動画エリア下部：決め台詞「みんなが見てない世界を見せてやるぜ」を開始時に表示しフェードアウト
- 動画エリア中央上寄り：登録者数の増減が5万人以上のときに要因
  （例：「+1,500,000 登頂中」「-2,000,000 被弾」）をポップアップ表示する（緑＝増加、赤＝減少）
- 下部バー：配信タイトル・登録者数（3桁区切り、増減の都度更新）・目標（1億人）に対する進捗バー・
  現在の到達階数（「現在 N 階」）・チャンネル情報（アイコン・チャンネル名「世紀の大盗賊CH【財宝山分けプロジェクト】」・
  視聴中人数・登録ボタン・高評価/共有）
- 右側パネル：ライブチャット欄。常時、既存視聴者による雑談コメントが一定間隔で流れる
  - 雑談コメントを送る既存視聴者は固定の6名で、到達階数に応じて登場するタイミングが異なる
    - 0階から：「塔の税務署」「1億人耐久@金塊待ち」
    - 20階から：「古事記のエルフ」「お宝クレクレスライム」
    - 30階から：「山分け希望のゴブリン」「錬金術失敗したマン」
- 登録者数が増えるたび（通常進行・階層到達ボーナス・財宝入手）、その都度ランダムに生成された
  「新しい視聴者」がチャットに登録コメント（例：「登録しました!!」）を投稿する演出を行う
  （名前は「接頭語＋名詞」のみで構成し、数字は付けない）。被弾・落下時は既存視聴者による
  反応コメントが流れる
- チャットのコメントはクリックすると削除できる（種類を問わず全コメント共通）。削除すると
  「（このコメントは削除されました）」という表示に置き換わる。UIの分かりやすさ（削除であることの
  明示的な演出など）は現時点では作り込んでおらず、将来的にゲーム性と結びつける可能性がある
- 1億人達成時の演出は動画エリア（配信画面）の中だけで完結させる。既存のような画面全体を覆う
  暗転・達成メッセージ・統計表示は行わず、動画エリア内で派手な演出（達成タイトルの拡大縮小、
  画面フラッシュ、絵文字の紙吹雪演出）を流しつつ、`assets/clear.mp3` を再生する。「もう一度プレイ」
  ボタンも動画エリア内に配置する（下部バー・チャット欄は隠さずそのまま表示し続ける）。達成中は
  ライブチャットが祝福コメントで超高速に流れ続ける
