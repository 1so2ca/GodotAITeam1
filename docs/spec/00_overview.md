## ゲームコンセプト

プレイヤーはゲーム内で配信活動を行い、その結果として得られる
「視聴者数」「チャンネル登録者数」が、実質的な**スコア／達成度の指標**として
機能する。

- ジャンプやアクションなどのプレイが上手くいく → ゲーム内で視聴者・登録者が増える
- 視聴者数・登録者数の増加が「跳ね上がる（Jump up!）」というテーマの表現になる

つまり「視聴者・登録者を集める」はマーケティング上の目標ではなく、**ゲームデザイン
上のスコアシステムのテーマ・見た目**である。詳細は
[03_viewer_score_system.md](03_viewer_score_system.md) を参照。
