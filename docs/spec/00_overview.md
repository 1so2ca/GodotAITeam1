## ゲームコンセプト

プレイヤーはゲーム内で配信活動を行い、その結果として得られる
「チャンネル登録者数」が、実質的な**スコア／勝敗条件の指標**として機能する。

- ジャンプボタンでジャンプし、敵との戦闘もジャンプ要素で行う
- ファンタジーな塔を登っていく様子を配信している、という設定
- 登録者数が「跳ね上がる（Jump up!）」瞬間（区切りの階への到達、財宝入手）を作ることがテーマの表現になる

つまり「視聴者・登録者を集める」はマーケティング上の目標ではなく、**ゲームデザイン
上のスコアシステムのテーマ・見た目**である。詳細は
[03_viewer_score_system.md](03_viewer_score_system.md) を参照。
