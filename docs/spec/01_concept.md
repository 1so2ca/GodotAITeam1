# コンセプト

## テーマ：「Jump up!」

「Jump up!」というテーマから連想されるキーワードや方向性をここに書き出していく。

- （例）物理的な「ジャンプ」アクション
- （例）ランキングや成績が「跳ね上がる」上昇志向
- （例）失敗してもすぐ「立ち上がる」テンポの良さ

### テーマの実現方法（決定）

- 基本操作はジャンプボタンでのジャンプ
- 敵との戦闘もジャンプ要素（踏みつけ等）で実現する
- チャンネル登録者数が区切りごとに一気に「跳ね上がる」演出でテーマを表現する

## ゲーム内の「配信」というスコアシステムについて

本作では、プレイヤーキャラクターがゲーム内で動画配信を行っている、という
設定になっている。プレイのうまさに応じてゲーム内の「チャンネル登録者数」が
増減し、これが実質的なスコア兼勝敗条件として機能する。詳細は
[03_viewer_score_system.md](03_viewer_score_system.md) を参照。

## ジャンル（決定）

**アクション系**に決定。ファンタジーな塔を登っていく様子を配信する、という
コンセプト。敵が出現し、ジャンプ要素を使った戦闘を行う。

検討時に比較した内容：

- スポーツ系（ミニゴルフ、パルクール系レースなど）は見送り
- アクション系は「Jump up!」というテーマとの親和性が高く、塔登り＋ジャンプ戦闘という
  分かりやすいコアループを作れると判断

具体的なゲームプレイ仕様は [02_gameplay.md](02_gameplay.md)、
登録者数の増減ルールは [03_viewer_score_system.md](03_viewer_score_system.md) を参照。

## 世界観・設定

- 舞台：ファンタジーな塔
- プレイヤーキャラクターは「みんなが見てない世界を見せてやるぜ」という決め台詞で配信を行っている
- チャンネル登録者数1億人を達成すると、塔の中で手に入れたもの（金銀財宝など）を配ると宣言している
- 塔の中で金銀財宝を入手するシーンは、実際にアイテムを付与するギミックというより**演出**として扱う
