# コンセプト

## テーマ：「Jump up!」

「Jump up!」というテーマから連想されるキーワードや方向性をここに書き出していく。

- （例）物理的な「ジャンプ」アクション
- （例）ランキングや成績が「跳ね上がる」上昇志向
- （例）失敗してもすぐ「立ち上がる」テンポの良さ

## ゲーム内の「配信」というスコアシステムについて

本作では、プレイヤー（またはプレイヤーキャラクター）がゲーム内で動画配信を
行っている、という設定になっている。プレイのうまさに応じてゲーム内の
「視聴者数」「チャンネル登録者数」が増減し、これが実質的なスコアとして
機能する。詳細は [03_viewer_score_system.md](03_viewer_score_system.md) を参照。

ジャンル検討にあたっては、このスコアシステムをどう表現しやすいかも観点に
含める。

## ジャンル候補

以下の2ジャンルを比較検討中。

### スポーツ系

- 例：ミニゴルフ、パルクール系レース、対戦スポーツのデフォルメ版 など
- 長所：ルールが直感的で視聴者に伝わりやすい、対戦性があると盛り上がる
- 短所：既存タイトルとの差別化が難しい場合がある

### アクション系

- 例：高難度プラットフォーマー、脱出系アクション、協力/対戦アクション など
- 長所：「Jump up!」というテーマと相性が良い、派手な演出を作りやすい
- 短所：操作難易度が高いと初見のプレイヤーが置いてけぼりになりやすい
