# ゲームプレイ仕様

ジャンル：アクション（ファンタジーな塔登り × ジャンプ戦闘）。
詳細は [01_concept.md](01_concept.md) を参照。

## コアループ

1. 塔を上へ登っていく
2. 道中に出現する敵とジャンプ（踏みつけ等）で戦闘する
3. 区切りの階に到達する／金銀財宝を入手する → チャンネル登録者数が一気に増加
4. 立ち止まる・落ちる・被弾するなどすると登録者数が減少
5. 登録者数が1億人に到達したらクリア

## 操作方法（決定）

| アクション | 入力（キーボード） | 入力（ゲームパッド） |
| --- | --- | --- |
| ジャンプ（移動・戦闘の基本操作） | Space / W / ↑ | Aボタン（下段ボタン） |
| 移動 | A / D、← / → | 十字キー左右 |

敵との戦闘は専用の攻撃ボタンを設けず、敵の真上からジャンプで踏みつけることで
撃破する（横・下から触れると被弾扱いになりダメージを受ける）。ただし無敵状態
（アイテム効果中）に敵へ触れた場合は、方向を問わず敵を倒す。

ジャンプには3フレーム分の先行入力（ジャンプ・バッファ）を持たせる。着地の直前に
ジャンプボタンを押しても、着地した瞬間に自動的にジャンプが発生する。

## スコアシステム（チャンネル登録者数）

ゲーム内でキャラクターが動画配信を行っている設定で、プレイの結果に応じて
「チャンネル登録者数」が増減し、これがスコア兼勝敗条件として機能する。
具体的な増減ルールは [03_viewer_score_system.md](03_viewer_score_system.md) で定義する。

## ルール・勝敗条件

- 勝利条件：チャンネル登録者数が1億人に到達する（スタート時は0人）
- ゲームオーバー条件：なし
- 登録者数は減少することがあり、その場合はゴール（1億人）から遠ざかる
  （＝詰みではないが後退はする）

## レベルデザイン方針（実装内容）

- 塔は階数制限なし。開始時に最初の40階分を生成し、以後はプレイヤーの到達に応じて
  常に先読みで上へ生成を続ける（無限に登り続けられる）
- ジグザグに配置した足場をジャンプで登っていく構成
- 足場の見た目は `assets/content_resize.png`（レンガ調のタイル画像）を敷き詰めて表示する
  （画像の透明な余白を切り出してから並べることで、タイルの継ぎ目に隙間ができないようにしている）
- 背景は `assets/background.png` を足場のブロックと同じサイズでループ表示する
  （塔の伸長に合わせて縦方向のループ範囲も拡張する）
- 主人公の見た目は `assets/touzoku.png` を使用する
- 敵の見た目は `assets/enemy.png` を使用する（移動方向に応じて画像を反転させる）
- 効果音：ジャンプ（`assets/player_jump.wav`）、被弾（`assets/player_damaged2.wav`）、
  敵撃破（`assets/enemy_killed2.wav`）、天井に頭をぶつけた時（`assets/player_headhurt.wav`）、
  アイテム取得時（`assets/player_getitem.wav`）、1億人達成（`assets/clear.mp3`）
- 隣り合う階の足場は、当たり判定の範囲が重ならないよう最低間隔を確保して配置する
  （＝真上にジャンプしても頭が上の階にぶつからない。間隔は横移動でジャンプして届く範囲に収める）
- 10階ごとにひときわ大きい足場＝チェックポイントを配置し（足場を金色に色調変更して区別）、到達で登録者数が一気に増加する
- 財宝（金銀財宝の演出）を8階ごとに1箇所配置
- 敵はおおむね3階ごと（チェックポイント・財宝の階を除く）に配置し、左右に巡回する
- 1プレイが3分〜10分未満に収まるボリュームで設計する（塔自体は無限だが、1億人到達で勝利となるため
  実際のプレイ時間はこの範囲に収まる想定）

## システム要件（実装内容）

- プレイ人数：1人プレイ
- プレイ時間の目安：10分未満（3分程度で成立するボリュームでもOK）
- 対応プラットフォーム：PC（Godot 4.7、キーボード / ゲームパッド対応）
