# ゲームプレイ仕様

ジャンル：アクション（ファンタジーな塔登り × ジャンプ戦闘）。
詳細は [01_concept.md](01_concept.md) を参照。

## コアループ

1. 塔を上へ登っていく
2. 道中に出現する敵とジャンプ（踏みつけ等）で戦闘する
3. 区切りの階に到達する／金銀財宝を入手する → チャンネル登録者数が一気に増加
4. 立ち止まる・落ちる・被弾するなどすると登録者数が減少
5. 登録者数が1億人に到達したらクリア

## 操作方法（決定）

| アクション | 入力（キーボード） | 入力（ゲームパッド） |
| --- | --- | --- |
| ジャンプ（移動・戦闘の基本操作） | Space / W / ↑ | Aボタン（下段ボタン） |
| 移動 | A / D、← / → | 十字キー左右 |

敵との戦闘は専用の攻撃ボタンを設けず、敵の真上からジャンプで踏みつけることで
撃破する（横・下から触れると被弾扱いになりダメージを受ける）。

## スコアシステム（チャンネル登録者数）

ゲーム内でキャラクターが動画配信を行っている設定で、プレイの結果に応じて
「チャンネル登録者数」が増減し、これがスコア兼勝敗条件として機能する。
具体的な増減ルールは [03_viewer_score_system.md](03_viewer_score_system.md) で定義する。

## ルール・勝敗条件

- 勝利条件：チャンネル登録者数が1億人に到達する（スタート時は0人）
- ゲームオーバー条件：なし
- 登録者数は減少することがあり、その場合はゴール（1億人）から遠ざかる
  （＝詰みではないが後退はする）

## レベルデザイン方針（実装内容）

- 塔は全40階。ジグザグに配置した足場をジャンプで登っていく構成
- 10階ごと（10 / 20 / 30 / 40階）にひときわ大きい黄金の足場＝チェックポイントを配置し、到達で登録者数が一気に増加する
- 財宝（金銀財宝の演出）を6箇所（5, 13, 17, 25, 33, 37階）に配置
- 敵は3階ごと（チェックポイント・財宝の階を除く）に配置し、左右に巡回する
- 1プレイが3分〜10分未満に収まるボリュームで設計する

## システム要件（実装内容）

- プレイ人数：1人プレイ
- プレイ時間の目安：10分未満（3分程度で成立するボリュームでもOK）
- 対応プラットフォーム：PC（Godot 4.7、キーボード / ゲームパッド対応）
